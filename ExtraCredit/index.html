Using a hybrid MPI+OpenMP approach to parallel and distributed computing is very common in a supercomputer environment. It allows for easy communication between nodes using MPI without sacrificing the ease of using OpenMP for node level parallelism. In addition, computing the Mandelbrot set presents a significant challenge due to the nature of the calculation.

Typically, one uses a single MPI rank per node to facilitate communication between nodes and OpenMP to utilize all the codes on each node. Use this approach when solving this problem. Because the result is a grayscale image of the Mandelbrot set, make sure you use the provided image tools C++ code that we used during the lectures. This code will write the matrix that you calculate to an image that you can download and viewed locally. Use what you have learned this semester to achieve that fastest calculation you can while ensuring that each node does approximately the same amount of work.
